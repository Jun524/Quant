# AOA 공개 체결 기반 행동 프로토타입

## 지위

- 전략명: `AoaBehaviorPrototype`
- 상태: **개발 진단 REJECTED — Experiment 0005 아님**
- 실거래/기본 dry-run 편입: 금지
- 근거 자료: 2018-03-01~2021-12-31 BitMEX 공개 체결·지갑 내역
- 중요한 제한: 근거 자료에서 조건을 발견했으므로 해당 기간은 전부 개발 데이터다. 이미 본
  Binance 2022~2026 데이터 역시 최종 미관측 OOS라고 부를 수 없다.

## 체결 기록에서 직접 관측한 것

1. 144만 체결 행은 약 144만 번의 독립 판단이 아니다. 일반 주문은 23,415개이고 주문당 부분
   체결 중앙값은 17개다.
2. 일반 주문 체결 수량의 73.4%가 maker다.
3. XBTUSD flat-to-flat 에피소드 2,655개의 중앙 보유시간은 24.9분이다. 승리 거래 21.5분,
   손실 거래 40.8분으로 손실을 더 오래 보유했다.
4. 24시간·168시간 방향과 진입 방향의 일치에서 더 높은 PF가 관측됐고, 24시간 방향에 맞춘
   1시간 되돌림 조합도 양의 PF였다. 이는 인과관계나 미래 edge의 증명이 아니다.
5. 불리한 방향의 추가 진입이 유리한 방향의 추가 진입보다 많았고, 강제청산 표시 체결도
   존재한다. 이 행동은 프로토타입에서 제거한다.

## 고정 번역 규칙

| 관측 | 프로토타입 번역 |
|---|---|
| 약 25분 중앙 보유 | 5분 신호봉, 5분 EMA12 모멘텀 이탈 청산 |
| 24h/168h 방향 정렬 | 완료된 1시간봉 24h·168h 수익률과 EMA200이 같은 방향일 때만 진입 |
| 짧은 되돌림 | 직전 3개 5분봉 수익률이 추세 반대이고 현재 종가가 직전 고가/저가를 재돌파 |
| 정상 이상 거래량 | 마지막 완료 1시간 거래량이 그 이전 24시간 중앙값 이상 |
| maker 중심 체결 | 호가 `same` 쪽의 limit 주문, 1분 미체결 취소 |
| 긴 손실 보유 | 24시간 최대 보유, 3% 비상 stop |

일봉 `PANIC`에서는 신규 진입하지 않는다. 롱·숏은 동일한 구조로 허용하되 1배, BTC 한 종목,
동시 한 포지션, 계좌 계획 위험 0.25%로 제한한다. 물타기와 포지션 증액은 꺼져 있다.

## 검증 전제

1. 5분봉 백테스트에서 수수료·펀딩을 포함한다.
2. `same` limit 주문은 메이커를 지향할 뿐 체결을 보장하지 않는다. 백테스트와 별도로 미체결률,
   취소 후 가격 이동, 실제 maker/taker 비율을 shadow/dry-run에서 기록한다.
3. 기본 수수료, 2배 수수료, 체결당 추가 슬리피지의 세 결과를 분리한다.
4. lookahead/recursive 검사를 모두 통과해야 한다.
5. Long/Short, BULL/BEAR/RANGE/TRANSITION, 시간대, 보유시간별 손익을 분리한다.
6. 강제 종료를 뺀 자연 청산 100건 미만이면 어떤 수익률도 승격 근거로 쓰지 않는다.
7. 향후 처음 도착하는 데이터에서 순손익 양수, PF 1.20 이상, 비용 스트레스 양수, 단일 승자
   집중도 허용 범위를 동시에 만족하기 전에는 Alpha 번호와 PASS를 부여하지 않는다.

## 의도적으로 복제하지 않은 것

- 정확한 레버리지와 재량 판단: 공개 체결로 식별 불가능하다.
- 무제한 분할 진입과 손실 중 물타기: 강제청산 위험을 키운다.
- BitMEX 역계약 XBT 손익을 Binance USDT-M 수익률로 환산하는 것: 계약 구조가 다르다.
- 하루 1% 목표를 맞추기 위한 파라미터 탐색: 관측을 목표 수익률에 맞추는 과최적화가 된다.

## 개발 진단 결과

2022-06-01~2026-09-01 Binance 5분봉에 편도 0.05% 수수료와 역사적 funding을 적용한 결과,
3,042거래에서 -16.80%, PF 0.519, 최대낙폭 17.08%였다. 추정 가격 PnL은 +3.22 USDT였지만
거래 수수료 -170.95 USDT와 funding -0.27 USDT를 지불할 edge가 없었다. 롱·숏과 네 Regime이
모두 음수였다.

따라서 추가 파라미터 탐색, 비용 스트레스, 승격 검사는 진행하지 않는다. 이는 구현 실패가 아니라
“공개 체결에서 관측한 방향·보유시간만으로 재량 edge를 복구할 수 없다”는 반증이다. 자세한 수치는
`reports/aoa-behavior-prototype-diagnostic.md`에 보존한다.
