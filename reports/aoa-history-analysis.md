# 워뇨띠 공개 체결 내역 분석

## 데이터 범위와 품질

- 실행 행: 1,444,583개, 실제 거래 체결 행: 1,439,207개
- 일반 주문: 23,415개. 한 주문의 부분 체결 중앙값은 17개다.
- 지갑 원장의 실현손익 합계는 3537.32 XBT지만, 잔액 재계산 불일치가 1,288행이라 정확한 수익률·낙폭 곡선으로 사용하지 않는다.
- 강제청산 표시 체결은 59행, 25일에 존재한다.

## 반복 행동

- 일반 주문 체결 수량의 메이커 비중은 73.4%다. 시장가보다 지정가·부분 체결 관리가 핵심이다.
- XBTUSD 경제적 flat-to-flat(1계약 잔여 무시) 에피소드는 2,655개, 중앙 보유시간은 24.9분이다.
- 승리 에피소드 중앙 보유시간은 21.5분, 손실은 40.8분이다.
- 진입과 청산 모두 여러 주문으로 나눴고, 추가 진입은 유리한 방향 2,356회와 불리한 방향 5,047회가 모두 존재한다.
- 시장 문맥: 24시간 방향 일치 1248개(PF 1.69), 그중 1시간 되돌림 566개(PF 1.67). 이는 원인 증명이 아니라 관측된 상관관계다.

## 행동 구간 진단

계좌 담보가 없어 실제 수익률을 계산할 수 없으므로 아래 PF는 `net_return_proxy` 기준이다. 포지션
크기의 영향을 줄인 비교값일 뿐이며 인과효과가 아니다.

| 관측 구간 | 에피소드 | 승률 | Proxy PF |
|---|---:|---:|---:|
| 진입 maker < 50% | 1,037 | 70.2% | 1.96 |
| 진입 maker >= 90% | 1,019 | 84.5% | 4.31 |
| 진입 주문 2~3개 | 701 | 79.5% | 4.12 |
| 진입 주문 10개 이상 | 238 | 58.0% | 1.37 |
| 불리한 추가진입 없음 | 1,418 | 79.7% | 3.54 |
| 불리한 추가진입 있음 | 1,237 | 71.6% | 1.99 |

높은 maker 비중은 좋은 신호라서가 아니라 체결되기 쉬운 시장 상태를 선택한 결과일 수 있다.
반대로 10회 이상 진입과 불리한 증액 구간의 PF 저하는 무제한 물타기를 복제하지 않을 근거를
강화한다. 따라서 시스템은 포지션 조정을 꺼둔 채, maker 효과는 실제 미체결까지 포함해 별도로
검증한다.

## 퀀트로 흡수할 요소

1. 24시간 방향 필터와 짧은 되돌림 진입을 독립 가설로 검증한다.
2. maker-first 주문을 사용하되 미체결과 대기 중 가격 이동을 비용으로 기록한다.
3. 진입·청산을 분할하되 총 위험예산은 첫 주문 전에 고정한다.
4. 승리보다 오래 지속되는 손실 포지션에는 시간 제한과 강제 축소 규칙을 둔다.
5. 펀딩·수수료·maker rebate를 가격손익과 분리한다.

## 복제하지 않을 요소

1. 강제청산과 무제한 물타기는 금지한다.
2. 공개 체결만으로 레버리지나 정확한 재량 신호를 추정하지 않는다.
3. 과거 BitMEX 역계약의 수익 규모를 Binance USDT-M 예상 수익률로 변환하지 않는다.
4. 이 자료에서 유도한 조건은 전부 개발 데이터로 간주하며, 새로운 미래 OOS 없이는 승격하지 않는다.
